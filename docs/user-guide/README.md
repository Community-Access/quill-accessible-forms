# BITS Accessible Forms (BAF) User Guide

Welcome to the BITS Accessible Forms (BAF) user documentation! BAF is an accessible WordPress form builder, built from the ground up for WCAG 2.2 AA compliance.

## Choice Libraries Reference

**Choice Libraries Reference** - Complete reference for all 125+ predefined choice libraries (see `docs/CHOICE-LIBRARIES.md`).

Includes:
- Geographic libraries (countries, 25+ country state/province lists, cities)
- Time & date libraries (timezones, time slots, days, months, years)
- Financial libraries (currencies, cryptocurrencies, budget ranges)
- Language libraries (50 languages, phone country codes)
- Demographic libraries (age, gender, education, employment, income)
- Professional libraries (60+ industries, job functions, experience levels)
- E-commerce libraries (sizes, colors, conditions, payment methods)
- Health & medical libraries (blood types, specialties, allergies)
- Rating & feedback libraries (satisfaction, agreement, likelihood scales)
- And many more!

## Accessibility First

BAF treats keyboard navigation as a **first-class citizen**:

- **Structure Mode**: Industry-first keyboard-native tree view for form organization
- **Complete keyboard shortcuts**: Every action has a keyboard equivalent
- **Screen reader optimized**: Proper ARIA labels and live announcements
- **Focus management**: Predictable, logical focus flow
- **High contrast support**: Works with Windows High Contrast Mode
- **Reduced motion**: Respects user preferences
